## 🚀 Proyectos destacados

### 🌌 Portfolio — Orbital

Portfolio profesional actualmente en desarrollo y mejora continua, desarrollado con Astro, React y Tailwind CSS, con una experiencia visual inspirada en el espacio y una navegación inmersiva.

Diseñé y desarrollé la interfaz, definiendo la identidad visual, sistema de navegación, animaciones e interacciones para crear una experiencia diferenciada de portfolio tradicional.

**Tecnologías:** Astro, React, TypeScript, Tailwind CSS, Git, GitHub, Vercel.

[🌐 Ver Portfolio](https://portfolio-seven-hazel-24.vercel.app) · [💻 Ver repositorio](https://github.com/1LuciaLemes/portfolio)

### Globalance

Billetera virtual multimoneda desarrollada en equipo, orientada a freelancers y profesionales para gestionar pagos y operaciones en distintas divisas.

Participé en la definición inicial del flujo y alcance de la aplicación y desarrollé funcionalidades frontend utilizando React y TypeScript.

Desarrollé funcionalidades de transferencias, conversiones, contactos, historial y notificaciones, además de un buscador global para consultar información de distintas secciones desde un único punto de acceso.

También implementé datos y servicios mock para permitir el desarrollo independiente del frontend mientras el backend se encontraba en desarrollo.

**Tecnologías:** React, TypeScript, Vite, Tailwind CSS, React Router, React Context, Firebase, APIs REST, Vitest, Recharts, Git, Vercel.

[Ver repositorio](https://github.com/Globallink-Studio/Frontend-Globalance)

### Ecommerce de perfumes

Aplicación web de ecommerce con un catálogo de 60 productos y funcionalidades para usuarios y administración de contenido.

Desarrollé integralmente la aplicación, trabajando en las interfaces, componentes, navegación, gestión de productos, carrito y flujo de compra.

Integré Firebase para la gestión de información y Amazon S3 para permitir al administrador agregar y editar imágenes de productos.

También implementé el envío de un correo electrónico después de confirmar una compra simulada, informando al usuario que la orden había sido confirmada.

**Tecnologías:** React, JavaScript, HTML, CSS, React Router, React Context, Firebase, Amazon S3, Git, GitHub.

[Ver repositorio](https://github.com/1LuciaLemes/ProyectoM5_LuciaLemes)

### Chat IA — Google Gemini

Aplicación web de una sola página (SPA) que integra Google Gemini AI para generar conversaciones con personajes de Harry Potter.

Implementé navegación entre distintas secciones mediante React Router, integración con la API de Gemini y una función serverless para evitar exponer la API key.

El proyecto también cuenta con diseño responsive y pruebas automatizadas.

**Tecnologías:** JavaScript, HTML, CSS, Google Gemini AI, Vercel Functions, Vitest, Vercel.

[Ver repositorio](https://github.com/1LuciaLemes/ProyectoM3_LuciaLemes)
